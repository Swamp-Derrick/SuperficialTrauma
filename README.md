# Superficial Trauma

Superficial Trauma is a server-authoritative trauma and emergency-medicine mod for Minecraft Forge 1.20.1. It adds persistent wounds, bleeding, infection, medication, incapacitation and resuscitation, lootable bodies, forensic examination, and medical crafting, with optional support for CGM and compatible gun addons.

The mod is currently in early development. Version `0.0.3-DEV` is a multiplayer-tested development milestone rather than a finished release.
