# Superficial Trauma

<img src="src/main/resources/superficialtrauma_icon.png" alt="Superficial Trauma icon" width="96" height="96">

Superficial Trauma is a server-authoritative trauma and emergency-medicine mod for Minecraft NeoForge 1.21.1. It adds persistent wounds, bleeding, infection, medication, incapacitation and resuscitation, lootable bodies, forensic examination, and medical crafting, with optional CGM gun support and Simple Voice Chat integration.

The mod is in early development. `1.21.1-dev` targets Java 21 and NeoForge 21.1.252. Previous Forge 1.20.1 development is discontinued. Version [0.0.5](https://github.com/Swamp-Derrick/SuperficialTrauma/releases/tag/v0.0.5) is an early testing release; see the [compatibility baseline](COMPATIBILITY.md) before installing.
