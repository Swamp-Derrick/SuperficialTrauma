# Superficial Trauma

Superficial Trauma is a server-authoritative trauma and emergency-medicine mod for Minecraft NeoForge 1.21.1. It adds persistent wounds, bleeding, infection, medication, incapacitation and resuscitation, lootable bodies, forensic examination, and medical crafting, with optional support for CGM and compatible gun addons.

The mod is in early development. The default development branch, `1.21.1-dev`, targets Java 21 and NeoForge 21.1.252. Forge 1.20.1 development and old-world migration are on hold. Version `0.0.4-DEV` is a test build, not a finished release. See [migration notes](MIGRATION_1.21.1.md) and the [compatibility baseline](COMPATIBILITY.md) before testing.
